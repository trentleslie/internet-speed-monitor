# Phase 2: WiFi Signal Quality Testing

**Purpose:** Compare WiFi performance at different house locations to optimize Raspberry Pi placement for streaming
**Status:** 🔄 In Progress

---

## Overview

Phase 2 aims to identify the optimal location in the house for placing a Raspberry Pi-based streaming setup. By measuring WiFi signal strength, router latency, and throughput at multiple locations, we can make data-driven placement decisions.

### Testing Methodology

- **Device:** Raspberry Pi connected via WiFi (wlan0)
- **Router:** TP-Link Deco BE25 (WiFi 7 mesh system)
- **ISP:** Astound Broadband (following Phase 1 recommendation)
- **Metrics Captured:**
  - WiFi signal strength (%)
  - Channel and BSSID
  - Router ping latency (10 samples)
  - Optional speed test (download/upload)
- **Monitoring Frequency:**
  - Signal/ping: Every 5 minutes
  - Speed test: Every 30 minutes

## Sub-Phase 2.1: Dining Room (Baseline)

**Data Collection Period:** April 8-9, 2026
**Total Samples:** 247 signal/ping tests, ~50 speed tests

### Summary Statistics

| Metric | Value | Assessment |
|--------|-------|------------|
| Signal Strength | 97-100% | EXCELLENT |
| Router Latency (avg) | 5.5-7 ms | EXCELLENT |
| Latency Variance | ±1-2 ms | Very stable |
| Packet Loss | 0% | Perfect |
| Download Speed | ~47 Mbps | Good (WiFi limitation, not ISP) |
| Upload Speed | ~53 Mbps | Excellent for streaming |

### Observations

1. **Signal Quality:** The dining room receives excellent WiFi coverage with consistent 97-100% signal strength, likely due to proximity to a Deco mesh node.

2. **Router Latency:** Sub-7ms average latency to the router indicates minimal WiFi contention and excellent local network performance.

3. **Speed vs Wired:** The ~47 Mbps download via WiFi is significantly lower than the ~940 Mbps available on wired Ethernet. This is expected given WiFi overhead and the mesh network architecture.

4. **Streaming Viability:** With 53 Mbps upload and stable low-latency connection, this location easily supports 4K streaming (25 Mbps requirement) with significant headroom.

### Dining Room Assessment: ✓ VIABLE

The dining room provides excellent WiFi performance suitable for streaming. It will serve as the baseline for comparing other locations.

## How to Test a New Location

1. Move the Raspberry Pi to the new location
2. Set the location name:
   ```bash
   python wifi_test.py --set-location living_room
   ```
3. Let automated monitoring collect data for 12-24 hours
4. Run analysis:
   ```bash
   python analyze_wifi.py
   ```
